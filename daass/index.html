Instructor Operations Control Tower

A simple operational control layer for instructor onboarding. Communication can stay in email, WhatsApp and other tools; this view tells the team what that information means operationally.
Prototype • demo data only

Operating logic

Single source of operational truth: every instructor has one owner, one current stage, one next action, one due date, and visible blockers. Completion should be backed by evidence or a link—not by assumption. The CEO sees exceptions and decisions, not every task.

Before full implementation

Clarify who owns each stage, which system is authoritative for files, what actually requires CEO approval, standard turnaround times, and which communications can be automatically captured. Assumption for this prototype: Google Workspace or an equivalent shared file system is available.
